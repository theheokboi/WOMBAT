# Facility Density Algorithms

This directory records versioned behavior notes for the facility-to-cell algorithm behind `facility_density_adaptive`.

Use one file per published or meaningfully tested version:

- `v3.md`
- `v4.md`
- `v5.md`

Each version note should capture:

- intent
- inputs and coverage assumptions
- stopping and refinement rules
- smoothing and compaction behavior
- output and metadata shape
- known tradeoffs versus the previous version
- linked fixtures or comparison tests
